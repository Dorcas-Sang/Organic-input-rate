# Organic-input-rate
This is the new repository for the mode of multiobjective achievement with organic input rate. Replacing the Multi_objective achievement model that is faulty. 

This project identifies crop- and soil-specific organic-input rates for maize and soybean systems across upper, middle and lower slope positions in northern Ghana using a multi-objective probabilistic model. The probabilistic model evaluates the simultaneous achievement of soil organic carbon, crop-yield and farm-profitability objectives under uncertainty. The model outputs include: 1.crop- and soil-specific organic-input optima 2.probabilities of jointly achieving all objectives 3.soil organic carbon after 25 years, mean annual crop yield and farm profit at Oi rate 4. Sensitivity analysis

The repository contains the model (Multi_objective_satisfaction_model_R) and the Excel workbook of input distributions (input_estimates.xlsx). Model outputs, tables and figures are stored in the outputs folder.
